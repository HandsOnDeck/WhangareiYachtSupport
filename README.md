# Whangarei Yacht Support

Marketing website for Whangarei Yacht Support — professional yacht guardianage, project management/owner representative services, and Totara Apartment accommodation in Northland, New Zealand.

## Tech Stack

- **Frontend:** Next.js 16, React 19, Tailwind CSS 4

## Features

- Responsive, mobile-first design with navy/ocean/sand palette
- Home, Guardianage, Project Management, Accommodation, About, Testimonials, Contact
- SEO optimised with meta tags, structured data (JSON-LD), sitemap, and robots.txt
- Contact via phone / WhatsApp / email (mailto & tel links)

## Getting Started

### Prerequisites
- Node.js 20+

### Setup

```bash
npm install
cp .env.example .env
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deployment

Deploy to Vercel or any Node.js host:

1. Connect the GitHub repository
2. Set `APP_URL` (and optional map embed) if needed
3. Deploy
